# TANIS ATLAS — แผนที่ภูมิศาสตร์ดิจิทัล

เว็บไซต์โครงงานภูมิศาสตร์ นำเสนอ **7 สถานที่สำคัญทั่วโลก** ผ่านแผนที่โลกแบบอินเทอร์แอกทีฟ
พร้อมคำอธิบายทางภูมิศาสตร์ และการประยุกต์ใช้ **RS (Remote Sensing)** กับ **GNSS**

> กำหนดส่ง: **16 กันยายน**

---

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install      # ติดตั้งครั้งแรกครั้งเดียว
npm run dev      # เปิดเว็บไซต์สำหรับพัฒนา → http://localhost:5173
```

### สร้างไฟล์สำหรับนำเสนอ / อัปโหลด

```bash
npm run build    # ผลลัพธ์อยู่ในโฟลเดอร์ dist/
npm run preview  # ทดลองดูผลลัพธ์จริงก่อนนำเสนอ
```

โฟลเดอร์ `dist/` เป็นไฟล์สแตติกล้วน อัปโหลดขึ้น GitHub Pages, Netlify หรือ Vercel ได้ทันที
**ฟอนต์และแผนที่ถูกเก็บไว้ในโครงการทั้งหมด เว็บไซต์จึงทำงานได้แม้ไม่มีอินเทอร์เน็ตในวันนำเสนอ**

### 📦 รวมเหลือไฟล์เดียวสำหรับวันนำเสนอ (แนะนำ)

```bash
npm run build:single    # ได้ไฟล์ dist/tanis-atlas.html เพียงไฟล์เดียว (~0.8 MB)
```

ไฟล์นี้ฝังทั้ง CSS, JavaScript, ฟอนต์ และภาพไว้ข้างในหมดแล้ว
ก๊อปใส่แฟลชไดรฟ์ ส่งทางอีเมล หรือดับเบิลคลิกเปิดในเบราว์เซอร์ได้เลย
ไม่ต้องมีอินเทอร์เน็ต ไม่ต้องติดตั้งอะไร ไม่ต้องรันเซิร์ฟเวอร์

> ทำสำเนาไฟล์นี้ไว้ในแฟลชไดรฟ์เสมอ เผื่อคอมพิวเตอร์ในห้องนำเสนอต่อเน็ตไม่ได้

## 📝 ต้องแก้ไขอะไรบ้าง (สำคัญที่สุด)

ข้อมูลทั้งหมดอยู่ใน **2 ไฟล์** เท่านั้น ไม่ต้องแตะโค้ดส่วนอื่น

### 1. `src/data/locations.ts` — ข้อมูล 7 สถานที่

| ฟิลด์ | ต้องใส่อะไร |
|---|---|
| `name` | ชื่อสถานที่ (ภาษาไทย) |
| `officialName` | ชื่อทางการ/ชื่อสากล |
| `country` / `flag` / `continent` | ประเทศ · ธงอิโมจิ · ทวีป |
| `coordinates` | **พิกัดจริง** `{ lat, lng }` — กำหนดตำแหน่งหมุดบนแผนที่ |
| `image.src` | พาธของภาพ เช่น `images/tokyo.jpg` |
| `image.credit` | แหล่งที่มาของภาพ (ควรใส่เสมอ) |
| `summary` | สรุปสั้น 1 ประโยค (แสดงบนการ์ดและบนแผนที่) |
| `geography.description` | คำอธิบายทางภูมิศาสตร์ |
| `geography.facts` | ตารางข้อมูล (ป้ายกำกับ + ค่า) |
| `remoteSensing` | ข้อมูล **RS** — `lead` + `points` 3 ข้อ |
| `gnss` | ข้อมูล **GNSS** — `lead` + `points` 3 ข้อ |
| `owner` | ชื่อผู้รับผิดชอบ (ต้องตรงกับใน `team.ts`) |
| `isPlaceholder` | เปลี่ยนเป็น `false` เมื่อใส่ข้อมูลจริงครบ → ป้าย “ข้อมูลตัวอย่าง” จะหายไป |

**เรื่องพิกัด** — `lat` เหนือ = บวก / ใต้ = ลบ, `lng` ตะวันออก = บวก / ตะวันตก = ลบ
ค้นพิกัดได้จาก Google Maps โดยคลิกขวาที่จุดนั้น แล้วคัดลอกเลขสองตัวที่ขึ้นมา

### 2. `src/data/team.ts` — ผู้รับผิดชอบ + ข้อมูลโครงงาน

- `projectInfo` — รายวิชา, ระดับชั้น, โรงเรียน, ครูผู้สอน, ปีการศึกษา
- `team` — ชื่อสมาชิก, บทบาท, ชั้น/เลขที่ และ `locationIds` ของสถานที่ที่รับผิดชอบ

### 3. ภาพสถานที่

วางไฟล์ภาพใน `public/images/` แล้วแก้ `image.src` ใน `locations.ts`

- แนะนำภาพ **แนวนอน อัตราส่วน 16:10** ขนาดอย่างน้อย **1600 × 1000 px**
- ไฟล์ `placeholder-01.svg` … `placeholder-07.svg` เป็นภาพตัวอย่าง ลบได้เมื่อไม่ใช้แล้ว
- ภาพตัวอย่างจะมีข้อความ `REPLACE THIS IMAGE` เพื่อให้เห็นชัดว่ายังไม่ได้แทนที่

    │   ├── Hero.tsx            ส่วนหัวหน้าแรก
    │   ├── HeroGlobe.tsx       ลูกโลกหมุนได้
    │   ├── WorldMap.tsx        🗺️ แผนที่โลกอินเทอร์แอกทีฟ
    │   ├── LocationRail.tsx    รายการสถานที่ข้างแผนที่
    │   ├── LocationCard.tsx    การ์ดสถานที่
    │   ├── LocationDetail.tsx  แผงรายละเอียด + RS/GNSS
    │   ├── TechSection.tsx     ส่วนอธิบาย RS และ GNSS
    │   ├── TeamSection.tsx     ผู้รับผิดชอบ (การ์ด + ตาราง)

    ├── lib/format.ts           จัดรูปแบบพิกัดและตัวเลข
    └── styles/

        ├── tokens.css          🎨 สี ตัวอักษร ระยะห่าง (แก้ธีมที่นี่)
        ├── base.css            รีเซ็ตและยูทิลิตี้
        └── app.css             สไตล์ของแต่ละส่วน

## วิธีใช้แผนที่

| การกระทำ | ผลลัพธ์ |
|---|---|
| ลากเมาส์ / นิ้ว | เลื่อนแผนที่ |
| เลื่อนล้อ / ปุ่ม `+` `−` | ซูมเข้า–ออก |
| ชี้ที่หมุด | แสดงการ์ดตัวอย่างสถานที่ |
| คลิกหมุด | ซูมเข้าหาหมุด และเปิดแผงรายละเอียด |
| `Esc` | ปิดแผงรายละเอียด |
| `←` `→` | เปลี่ยนสถานที่ก่อนหน้า/ถัดไป (ใช้ตอนนำเสนอ) |
| ปุ่ม `รีเซ็ตมุมมอง` | กลับไปมุมมองแผนที่โลกทั้งใบ |

## เทคโนโลยีที่ใช้

| ส่วน | เครื่องมือ | เหตุผล |
|---|---|---|
| โครงสร้าง | Vite + React 18 + TypeScript | เร็ว จัดระเบียบโค้ดได้ดี สร้างไฟล์สแตติกได้ |
| แผนที่ | `d3-geo` + `topojson-client` + Natural Earth | แผนที่ SVG ที่ออกแบบเองได้ทั้งหมด **ไม่ต้องต่ออินเทอร์เน็ต ไม่ต้องใช้ API key** |
| สไตล์ | CSS ที่เขียนเองพร้อมระบบ design token | ควบคุมรูปลักษณ์ได้ละเอียด ไม่ดูเหมือนเทมเพลตสำเร็จรูป |
| ฟอนต์ | IBM Plex Sans Thai · Sarabun · IBM Plex Mono | เก็บไว้ในโครงการ (SIL Open Font License 1.1) |

รวมแพ็กเกจที่ใช้ตอนรันจริงเพียง 4 ตัว ไม่มี dependency ที่ไม่จำเป็น

## การเข้าถึงและการใช้งาน

- รองรับการใช้งานด้วยแป้นพิมพ์ทั้งเว็บไซต์ (รวมถึงหมุดบนแผนที่)
- มีลิงก์ข้ามไปยังเนื้อหาหลัก และป้ายกำกับ ARIA สำหรับโปรแกรมอ่านหน้าจอ
- เคารพการตั้งค่า `prefers-reduced-motion` — ปิดอนิเมชันทั้งหมดให้ผู้ใช้ที่ต้องการ
- มีทั้งโหมดมืดและโหมดสว่าง (จดจำค่าที่เลือกไว้) เผื่อโปรเจกเตอร์แสดงสีเข้มได้ไม่ดี
- รองรับการพิมพ์ออกกระดาษ (ซ่อนเมนูและปุ่มควบคุมอัตโนมัติ)
