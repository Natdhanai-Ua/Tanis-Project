# 📷 โฟลเดอร์ภาพสถานที่

วางไฟล์ภาพของทั้ง 7 สถานที่ไว้ในโฟลเดอร์นี้ แล้วแก้ `image.src` ในไฟล์ `src/data/locations.ts`

## ตัวอย่าง

วางไฟล์ `tokyo-disneyland.jpg` ไว้ที่นี่ แล้วแก้ใน `locations.ts` เป็น

```ts
image: {
  src: 'images/tokyo-disneyland.jpg',
  alt: 'ภาพสถานที่ โตเกียวดิสนีย์แลนด์ ประเทศญี่ปุ่น',
  credit: 'ที่มาของภาพ: ...',
},
```

## ข้อแนะนำ

| หัวข้อ | ค่าที่แนะนำ |
|---|---|
| อัตราส่วน | แนวนอน 16:10 |
| ขนาด | อย่างน้อย 1600 × 1000 พิกเซล |
| นามสกุล | `.jpg` (ภาพถ่าย) หรือ `.webp` (ขนาดเล็กกว่า) |
| ขนาดไฟล์ | ไม่เกินประมาณ 500 KB ต่อภาพ เพื่อให้เว็บไซต์โหลดเร็ว |

## ไฟล์ตัวอย่าง

`placeholder-01.svg` … `placeholder-07.svg` เป็นภาพตัวอย่างที่มีข้อความ `REPLACE THIS IMAGE`
เพื่อให้เห็นชัดว่าสถานที่ใดยังไม่ได้ใส่ภาพจริง — ลบทิ้งได้เมื่อใส่ภาพจริงครบแล้ว

สร้างภาพตัวอย่างใหม่ได้ด้วยคำสั่ง

```bash
node scripts/generate-placeholders.mjs
```

## ⚠️ เรื่องลิขสิทธิ์ภาพ

ใช้ภาพที่มีสิทธิ์ใช้งานเท่านั้น เช่น ภาพที่ถ่ายเอง ภาพจาก Wikimedia Commons, Unsplash หรือ Pexels
และควรระบุแหล่งที่มาในฟิลด์ `credit` ทุกครั้ง — เว็บไซต์จะแสดงให้ในแท็บ “ข้อมูลภูมิศาสตร์”
